## First launch

The game is not signed with a paid certificate yet, so the system asks once before opening it.

- **Windows:** on "Windows protected your PC", click **More info**, then **Run anyway**.
- **macOS:** open the game once, close the warning, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
  If macOS says the app is damaged, run `xattr -cr "/Applications/Prehistoric Tribes.app"` in Terminal.
- **Linux:** make the AppImage executable (`chmod +x`) and run it.
